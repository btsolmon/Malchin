# Малчин — Сүрэг хамгаалал

Монгол малчны survival тоглоом (Next.js + Canvas).

## Зорилго

10 хоньтой эхэлж **1000 хонь** цуглуул.

## Удирдлага

- **WASD** — хөдлөх
- **Space / J** — чоно, хулгайчтай тулалдах
- **E** — мод огтлох / жимс түүх
- **Q** — жимс идэх
- **F** — гал түлэх (шөнө)

## Ажиллуулах

```bash
bun install
bun dev
```
