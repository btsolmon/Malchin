# Малчин — Нүүдэлчин

Монгол малчны survival тоглоом. Next.js + HTML canvas дээр бүтээгдсэн, браузерт шууд ажиллана.

## Тоглоомын түүх

Аав ээж нь шуурганд сураггүй болсон хүү нэг хонь, нэг ямаа, нэг үхэртэйгээ талд бие даан үлддэг. Голомтоо ахин ассан, тарсан малаа хуруйсан, өвгөнөөс уламжлалт мэдлэг сурсан хүү сүүлдээ сүнсний ертөнцөд гарч, аав ээжийг нь авсан **Төмөр шулмас**тай тулна. Шулмасыг дийлээд эргэж ирэхэд гэр бүл эргэн нэгдэж **ЯЛАЛТ** зарлагдана. Түүнээс хойш сүргээ өсгөх төгсгөлгүй survival үргэлжилнэ — дайралт харин хүчээ авна.

Түүх 18 үндсэн зорилгоор өрнөнө: голомт ассах → тарсан мал хайх → сүргээ хамгаалах → чонын хөдөлгөөнийг ажиглах → сөрөх (parry) сурах → өвгөнтэй уулзах → шуурганы сураг шинжих → сүнсний ертөнц → Хөх тэнгэрийн сэлэм → Хар төмөр хаалга → Төмөр шулмас → гэр бүл эргэн нэгдэх → сүрэг өсгөх.

## Удирдлага

| `Q` | Жимс / загас / ааруул идэх |

| `B` | Хашаа барих / шинэчлэх |

### Утас (браузер)

Линкээр орж тоглоно — апп суулгах шаардлагагүй. **Утсаа хэвтүүлээд** (landscape) тоглоорой.

- Зүүн: joystick
- Баруун: Hit / Dodge / Parry / Use / Bow / Eat / Fire
- Дээд баруун: түр зогсоох

## Систем

- **Мал** — 5 хошуу мал (хонь, ямаа, үхэр, морь, тэмээ). Өсгөнө, ноос/ноолуур/сүү өгнө, өлсвөл хорогдоно.
- **Улирал ба өдөр** — нэг өдөр 4 минут, нэг улирал 6 өдөр. Өвөл өвс хатаж, тэвшний өвс шаардлагатай болно.
- **Тулаан** — тамир, бултах, сөрөх, тэвчээр (posture) бүхий фаз бүхий систем. Чоно, хулгайч, баавгай, сүнсний дайснууд, boss-ууд.
- **Урлал ба дэлгүүр** — гэртээ эсгий, ааруул, сум урлана; өвгөнөөс бараа авна.
- **Соёлын асуулт** — өвгөн уламжлалт ахуйн 153 асуулт (142 асуулт + 11 цаг агаар, нүүдлийн оньсого) тавьж, зөв хариултад зоос шагнана.
- **Хадгалалт** — 8 секунд тутам автоматаар хадгалагдаж, цэсний "Үргэлжлүүлэх"-ээр эргэн орно.
- **Дээд амжилт** — амьдарсан өдөр, хамгийн их мал, зоос браузерт бүртгэгдэнэ.
- **Хэл** — Монгол / English. Тохиргооноос солино.

## Техник

Дүрслэлийн бараг бүх зүйл (тал, гэр, мал, дүрүүд, эффект) **кодоор процедурээр зурагддаг** — зургийн файл цөөн. Тоглогчийн дүр процедурээр зурагддаг (sprite файл байхгүй); boss Төмөр шулмас дээр sprite sheet бий. Дуу нь Web Audio API-гаар шууд синтезчлэгддэг. Тиймээс татах хэмжээ маш бага.

```
lib/game/     тоглоомын логик (37 модуль)
  engine.ts     үндсэн цикл, оролт, төлөв
  types.ts      бүх төрөл ба тогтмол
  story.ts      түүх, зорилго, milestone
  ui.ts         меню, HUD, дэлгүүр, minimap
  render/       зурах давхаргууд
  combat/       тулааны систем
  i18n.ts       хэлний толь
  save.ts       хадгалалт
components/   React дээрх modal-ууд (өвгөний харилцан яриа)
app/          Next.js хуудас
public/assets/ гэрийн зураг, тал, boss-ийн sprite
```

## Ажиллуулах

```bash
bun install
bun dev
```

http://localhost:3000

Утаснаас ижил Wi‑Fi дээр: `http://<компьютерийн-IP>:3000` (жишээ: `192.168.1.8:3000`)

Шалгах:

```bash
bun x tsc --noEmit   # төрлийн шалгалт
bun run lint         # eslint
bun run build        # production build
```

### Олон нийтэд гаргах (Vercel)

Кодыг `main` руу push хийгээд Vercel GitHub-тай холбосон бол автоматаар deploy хийнэ. Эсвэл:

```bash
bunx vercel login
bunx vercel --prod
```

Гарах линкийг найз нөхөд / Discord / сошиалд тараана.
